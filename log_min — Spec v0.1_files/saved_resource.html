Log viewer + command runner desktop cho dev: tail file, chạy & quản lý npm run dev/mvn… ngay trong app, pull log từ HTTP(S) endpoint / server remote, nhận stream qua port — highlight theo level, tự gom stack trace thành block, dedup lỗi kiểu mini-Sentry, click file:line mở thẳng editor, copy nhanh mọi thứ.

Tauri v2 React + zustand Rust core: notify, tokio Scaffold: copy kafka_ui_min

1. Vấn đề & thesis

Trên macOS chưa có log viewer GUI gọn: Console.app tệ với log app tự viết, lnav là TUI, còn tail -f | grep mất trace nhiều dòng. Điểm đau lớn nhất không phải "xem log" mà là từ dòng ERROR đến file đang lỗi — mắt phải tự parse stack trace rồi gõ lại path vào editor.

Thesis: log_min biến log thô thành đối tượng có cấu trúc — mỗi error là một block gom sẵn, có fingerprint, có counter, và mỗi frame là một link mở editor. Không phải text viewer, là error navigator.

Quyết định 1 — parse ở đâu?

Rust chỉ lo I/O + batching; toàn bộ parse/detect chạy trong Web Worker TS. Regex trace đổi thường xuyên lúc tune — iterate TS nhanh hơn rebuild Rust. Worker giữ main thread rảnh cho render. Nếu profiling cho thấy worker nghẽn (>50k dòng/s) mới hạ parser xuống Rust — API event không đổi nên swap được.

Quyết định 2 — bộ nhớ

Ring buffer cố định 200 000 dòng/source, cũ nhất bị đẩy ra. Không ghi DB, không index full-text. Search = scan buffer trong worker (200k dòng regex scan ~vài chục ms). Cần lịch sử lâu hơn → v2 (SQLite optional).

Quyết định 3 — backpressure

Nguồn spam nhanh hơn UI nuốt → Rust batcher giữ bounded queue, tràn thì đếm số dòng drop và hiện trên status bar ("drop: 1 204") thay vì âm thầm mất. Pause (⌘↵) thì Rust vẫn đọc, chỉ ngừng emit — resume không mất khúc giữa (trong giới hạn buffer Rust 50k).

Data model (TS)

type Source = { id, kind: 'file'|'cmd'|'port'|'http', config, status: 'live'|'idle'|'error' }
type Line   = { seq, sourceId, ts?, level?, raw, fmt: 'json'|'logfmt'|'plain' }
type Trace  = { id, sourceId, lang, message, frames: Frame[], fingerprint,
                count, firstSeq, lastSeq }
type Frame  = { fn, path, line, col?, isApp: boolean }   // isApp = trong project root

5. Trace detection — phần ăn tiền

State machine trên stream dòng: một dòng khớp trace-start (message exception) mở block, các dòng sau khớp frame pattern của cùng ngôn ngữ thì append, dòng đầu tiên không khớp thì đóng block. Parser per-language, thứ tự thử: Node/TS → Python → JVM → Rust panic → Go goroutine.

Ngôn ngữFrame pattern (rút gọn)Ghi chú
Node/TSat fn (path:line:col)Cả dạng async, anonymous, node:internal đánh dấu non-app.
PythonFile "path", line N, in fnBlock bắt đầu bằng Traceback (most recent call last):; message ở dòng cuối.
Java/JVMat pkg.Cls.m(Cls.java:N)Nối Caused by: chains vào cùng block; map package→path cần source root config.
RustN: fn\n at path:linePanic + RUST_BACKTRACE=1 format.
Gofn(args)\n\tpath:line +0x…Goroutine dump header goroutine N [state]:.
  • Fingerprint = hash(exception type + top 3 app-frames đã normalize path). Cùng fingerprint → gom nhóm, tăng counter — panel Error groups.
  • isApp frame: path nằm dưới project root của source (config mỗi source, auto-đoán từ path chung dài nhất). Frame non-app (node_modules, stdlib) mờ đi + collapse mặc định.
  • Mở editor: setting toàn cục, URL scheme per editor: vscode://file/P:L:C, cursor://file/P:L:C, zed://file/P:L:C, JetBrains idea://open?file=P&line=L. Path relative resolve qua project root. Fallback luôn có: copy path:line.

6. Sources

KindRust implEdge cases phải xử
File tailnotify watch + seek đọc phần mớiRotation (inode đổi → reopen), truncate (size giảm → seek 0), file chưa tồn tại (chờ xuất hiện), dòng cuối chưa có \n.

Porttokio TCP accept nhiều conn / UDP socketBind fail (port bận) → error rõ, mỗi TCP conn tag peer, frame theo newline.
HTTP(S)reqwest streaming / pollingAuto-detect: SSE (text/event-stream) và chunked stream đọc liên tục; response thường → poll interval + Range/offset chỉ lấy phần mới. Custom headers (Bearer token), toggle "allow self-signed" per source, reconnect + backoff, lần đầu chỉ lấy tail N KB cuối.

Pull log từ server remote (IP)

  • Server expose log qua HTTP/SSE → source HTTP(S) ở trên, dán URL + token là chạy.
  • Server chỉ có SSH → không cần source kind riêng: command runner chạy ssh user@ip tail -F /var/log/app.log là xong — kill tree, restart, trace detection đều hoạt động y hệt. ⌘K palette có sẵn template "SSH tail…" điền host/path. ponytail: SSH first-class source (saved host, key picker) chỉ làm ở v2 nếu template thấy thiếu.
  • Server push được → port listener: server tail -F x.log | nc <máy-mình> 5514.

Command source = runner đúng nghĩa, không chỉ log source

Tab command là nơi chạy và quản dev process, thay cửa sổ terminal thả rông:

  • Lifecycle: nút ▶ Start / ⏹ Stop / ⟳ Restart ngay trên tab toolbar. Stop = kill cả process tree (killpg). Exit → banner "exited code 1 · 14:22:03 · ⟳ Restart", log giữ nguyên để đọc lý do chết.
  • Config per command: cwd (folder picker), env vars thêm/override, shell mặc định $SHELL -lc để ăn PATH từ nvm/sdkman.
  • Info bar (status bar của tab): trạng thái ● running/exited, pid, uptime, exit code, và runtime versions — detect từ lệnh: npm/node → node -v+npm -v, mvn → mvn -v (Java version), python, go, cargo… chạy một lần lúc start trong cùng cwd (đúng version nvm local), cache lại.
  • Project version: đọc package.json / pom.xml / Cargo.toml trong cwd → hiện tên + version project cạnh tên tab.
  • Stdin nhỏ: ô input gửi dòng vào stdin (đủ cho REPL prompt y/N). Không phải terminal emulator — không PTY, không TUI app (vim, htop). Ghi rõ giới hạn này trong UI.

7. Copy nhanh & UX "không khó chịu"

Copy — một cú click cho mọi thứ

  • Hover dòng log → nút copy mờ hiện bên phải: copy raw line. Chọn nhiều dòng (drag/⇧click) → ⌘C copy đúng phần chọn, giữ nguyên thứ tự, không lẫn cột UI (timestamp/level chỉ copy khi bật "copy full").
  • Trace block: nút Copy trace — nguyên stack đã de-collapse, sạch, paste thẳng vào issue/chat. Error group panel: copy message + trace + count.
  • Frame: click mở editor, ⌥click copy path:line.
  • ⌘⇧C = copy trace gần nhất đang nhìn thấy — lỗi vừa nổ, một phím là có trong clipboard.
  • Copy xong: toast nhỏ "Copied" góc dưới, tự tắt 1.5s, không animation màu mè.

8. Phasing

M1

Skeleton chạy được

Copy scaffold kafka_ui_min. File tail + command runner (▶/⏹/⟳, pid, exit code, kill tree), virtual list, level coloring, follow-mode không giật, ⌘F search, copy line/selection. Chưa có trace detection. Dùng được hằng ngày ngay từ đây.

M2

Error navigator

Trace state machine (Node + Python trước — hai format phổ nhất), trace block UI, fingerprint + Error groups panel, Copy trace / ⌘⇧C, click-to-editor (VS Code trước, setting configurable ngay sau), runtime versions + project version trên info bar. Đây là lúc app khác biệt với tail -f.

M3

Đủ scope v1

Port listener (TCP/UDP), HTTP(S) source (SSE/chunked/polling + auth header), JVM + Rust + Go parsers, JSON-lines pretty expand, logfmt, saved filters, regex highlight rules tự thêm, Errors tab tổng hợp, SSH tail template trong ⌘K.

v2+

Để sau, có chủ đích

SQLite history, docker/k8s source riêng (M1 đã cover qua spawn docker logs -f), source-map resolve cho JS minified, multi-source merge view theo timestamp, syslog protocol thật (RFC 5424).

10. Không làm (YAGNI)

  • Không full-text index / database — buffer scan đủ nhanh cho 200k dòng.
  • Không log shipping, không agent, không remote — local dev tool thuần.
  • Không AI phân tích lỗi — fingerprint regex đủ cho dedup.
  • Không plugin system cho parser — thêm ngôn ngữ = thêm file regex trong repo.
