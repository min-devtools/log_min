**Goal:** log_min M1 — Tauri log viewer + command runner: file tail + spawn command sources, virtual list, level coloring, follow mode, ⌘F search, quick copy. Usable daily from this milestone.

**Architecture:** Copy kafka_ui_min scaffold (shell, tabs, store, dialogs, themes byte-identical). Rust side = source engine only (I/O + batching, no parsing): tail/spawn readers → line assembler → batcher → `log:batch` events. TS side = ring buffer store + hand-rolled fixed-height virtual list. Level detection = cheap regex per batch (full parser worker is M2).

**Tech Stack:** Tauri 2, React 18, zustand 5, vite 5; Rust: tokio, notify 6, libc (killpg). Dropped from scaffold: rdkafka, react-query (M1 has no request/response reads), monaco (not needed for log lines).

**Spec:** artifact `log_min-spec.html` v0.2 (scratchpad copy; canonical decisions §4–§7).

## Global Constraints

- Family conventions (memory `min-app-family`): 6-file CSS cascade from `design-systems/`, `themes.ts`/`fontScale.ts` byte-identical, zustand `useApp`, `openDialog` promise, localStorage ns `log:`, tauri-plugin-store `log.json`, all Rust commands `Result<T,String>`, typed wrappers in `src/lib/logmin.ts`, macOS menu without File>Close.
- Ring buffer: 200_000 lines/source (TS), 50_000 lines bounded queue (Rust), overflow = counted drops, never silent.
- Batching: emit ≤ 30 events/s, ≤ 500 lines/batch.
- Follow mode never steals scroll: scrolling up disables follow instantly; floating "↓ N new lines" pill re-enables.
- No wrap by default (mono, horizontal scroll); no confirm dialog on process stop.
- Commands do NOT auto-restart on app relaunch — show ▶ instead.

### Task 1: Rust source engine

**Files:**
- Create: `src-tauri/src/sources.rs` (engine), rewrite `src-tauri/src/lib.rs` (commands + plugin setup + menu, keep macOS menu pattern from scaffold)
- Modify: `src-tauri/Cargo.toml` (drop rdkafka; add `notify = "6"`, `tokio = { version = "1", features = ["full"] }`, `libc = "0.2"`)

**Interfaces (produces — TS relies on exactly these):**
- Commands (all `Result<_, String>`):
  - `source_start(id: String, kind: "file"|"cmd", config: JSON) -> ()` — config file: `{path}`; cmd: `{command, cwd?, env?}`
  - `source_stop(id: String) -> ()` — file: stop watcher; cmd: SIGTERM process group, SIGKILL after 3s
  - `cmd_stdin(id: String, line: String) -> ()`
- Events:
  - `log:batch` `{ sourceId, firstSeq, lines: [{ seq, raw, stream: "out"|"err"|"file" }], dropped }`
  - `log:status` `{ sourceId, status: "live"|"idle"|"error", pid?, exitCode?, error?, startedAt? }`
- File tail: open + seek end (first attach reads last 64KB), notify watcher; rotation = inode change → reopen from 0; truncate = size < offset → seek 0; partial last line held until `\n`; file missing → watch parent dir, status `idle` until it appears.
- Cmd: `$SHELL -lc <command>`, `process_group(0)`, merged stdout/stderr readers (tagged), `killpg` on stop/app-exit; exit → `log:status {status:"idle", exitCode}`.
- Batcher: per-source task, mpsc bounded 50_000; flush every 33ms OR 500 lines; overflow increments `dropped` counter carried on next batch.

- [ ] Verify: `cargo check` clean
- [ ] Smoke test binary-side: `cargo test` unit tests for line assembler (partial line, rotation seek logic extracted as pure fn)

**Virtual list (hand-rolled, fixed row height):**
- Row height = `--lm-row-h` (font-scale aware via fontScale.ts), container `overflow: auto`, spacer div `height: total*rowH`, render `[floor(scrollTop/rowH) - 20, +viewport+40]` window from `Ring.slice`.
- Follow: `scrollTop = bottom` on batch when `follow[tab]`; `onScroll` if user moves up > 1 row → `follow=false`; pill "↓ N dòng mới" → re-enable.
- rAF-throttled render on `bufferVersion` change.

**Level coloring:** regex on raw: `/\b(ERROR|ERR|FATAL)\b/i` → red, `WARN` → orange, `INFO` → accent-2, `DEBUG|TRACE` → muted. Applied at render (memo per line id), not stored.

**Copy:** hover copy button per row (raw line); click row selects, ⇧click range; ⌘C copies selection raw joined `\n` via clipboard plugin; toolbar "Copy visible" fallback.

**⌘F:** inline bar under tabs; case-insensitive substring over `Ring` (scan in-memory), ↑/↓ jump match (scroll to seq, flash highlight), `Esc` closes, count "3/57".

**Cmd toolbar (kind=cmd):** ▶/⏹/⟳ buttons + stdin input row (Enter sends `cmd_stdin`); exited banner with code + ⟳.
